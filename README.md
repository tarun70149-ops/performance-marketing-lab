# Performance Marketing Lab

A GitHub Pages-based, WordPress-like practice environment for performance marketing,
conversion tracking, analytics, and funnel testing.

## Phase 1
- Modular theme registry
- Theme switcher
- Shared layout
- Dental / E-commerce / Business / Blog theme placeholders
- GitHub Pages-ready static architecture

## Run locally
Open `index.html` in a browser, or use any static local server.

## Deploy
Push the repository to GitHub and enable GitHub Pages from the repository settings.
